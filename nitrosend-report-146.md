- **Slowest step:** the signup email-verification step (~9 minutes). The verification email went to a forwarding alias and took minutes to surface in the inbox; the "paste the token" path needs a 300+ character token transcribed exactly, so we ended up clicking the "Finish signing up" link in the email instead, then "I already verified my email" in the editor. A secondary stall: the copied v0 chat's App Preview never rendered ("Your v0 generation will show here."), so the design was picked from the template page's own preview instead.
- **One change I would make:** offer a short numeric verification code next to the link/token for signup. The current token is impractical to copy by hand or from a screenshot (one wrong character fails), which is exactly the situation an agent-assisted signup hits.
- **Points where a person was needed:** setting the new account password (secure entry card; the agent never sees passwords), approving the password's use, and clicking the "Finish signing up" link in the verification email. Everything else — gallery, editing, saving, OAuth consent, subdomain prep, template query, and the send — was agent-run.
